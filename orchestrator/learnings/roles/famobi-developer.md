# famobi-developer — accumulated lessons

No accumulated lessons yet. Note: this role name is for projects with a **self-made** Famobi bridge
(hand-rolled Wrapper/Bridge/.jslib per feature, no vendor package). A project using the third-party
`com.famobi.game-interface` Unity package instead should use the sibling role `famobi-sdk-dev`, not this
one — don't conflate lessons between the two, the integration shape differs. Contribute short,
timestamped, generic entries here as you learn things worth carrying forward to the next project — no
project names, ticket IDs, or design specifics (see the subagent template's Tier B section for why).
